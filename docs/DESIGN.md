# 투자 대시보드 설계서 (v0.1 초안)

> 인터뷰 결과를 바탕으로 작성. 구현 전 확인용.

## 1. 한 줄 요약

미국 주식/ETF를 중기 스윙으로 투자하는 개인이 **대시보드 하나만 보고**
"무슨 일이 있었나 → 왜 그런가 → 내 종목에 어떤 영향인가 → 무엇을 할까"를
파악하고, 그 과정에서 **공부도 되는** 웹앱.

## 2. 요구사항 (인터뷰 결과)

| 항목 | 결정 |
|---|---|
| 시장 | 미국 주식/ETF |
| 투자 스타일 | 중기 스윙 (수주~수개월) |
| 보유 종목 | 10개 이하, 직접 입력 |
| 결정 지원 수준 | 매수/보유/매도 시그널 + 근거 |
| 첫 화면 | 오늘의 브리핑 |
| 맥락 층위 | 거시경제 · 섹터 · 뉴스/심리 · 실적/재무 (4개 모두) |
| 해설 | Claude API로 AI 해설 |
| 학습 요소 | 용어 툴팁 · 인과 흐름도 · 투자 일지 |
| 재무관리 | 투자 성과 · 자산 배분/리스크 |
| 형태 | Next.js 웹앱 |
| 데이터 | Alpha Vantage **무료 키** (하루 25회) |
| 알림 | 1차 버전 제외 |

## 3. 정보 흐름 (핵심 개념)

```
[데이터 수집]  →  [분석]            →  [해석]           →  [행동]
 시세/지표         추세·모멘텀 점수      Claude가 맥락·영향   시그널 + 근거
 뉴스/심리         뉴스 심리 점수        ·전망을 쉬운 말로    투자 일지 기록
 실적/재무         실적 서프라이즈        인과 흐름도 생성
 거시경제          시장 국면 판단
```

4개 층위는 위에서 아래로 영향을 줍니다:
**거시경제 → 섹터 → 개별 종목(실적·뉴스) → 내 포트폴리오**

## 4. 화면 구성

1. **오늘의 브리핑 (홈)**
   - AI 요약 3~5문장: "오늘 내 포트폴리오에 무슨 일이 있었고, 무엇을 봐야 하는가"
   - 시그널이 바뀐 종목 강조, 총자산/일간 손익 요약
2. **포트폴리오**
   - 종목별 손익, 수익률, S&P500(SPY) 대비 성과
   - 섹터 비중 차트, 집중도 경고, 목표 비중 대비 편차
3. **종목 상세**
   - 차트(가격 + 이동평균) + RSI/MACD
   - 4개 층위 카드: 거시 / 섹터 / 뉴스 / 실적
   - 시그널(매수·보유·매도) + 점수 근거 + AI 전망
   - 인과 흐름도: 예) 금리↑ → 성장주 할인율↑ → 이 종목 밸류에이션 부담
4. **시장 맥락**
   - 금리, 국채금리, 물가, 고용 추이 + "지금은 어떤 국면인가" 해설
   - 섹터 ETF 흐름
5. **투자 일지**
   - 매매 결정과 근거 기록 → 이후 결과 자동 비교(당시 가격 대비 현재)
6. **설정**: 보유 종목·수량·평단가·목표 비중 입력

전 화면 공통: 전문 용어에 마우스를 올리면 쉬운 설명이 뜨는 툴팁.

## 5. 시그널 로직 (규칙 기반 점수 + AI 해설)

점수는 규칙으로 계산해서 투명하게 보여 주고, AI는 해석만 맡습니다.

| 요소 | 가중치(초안) | 예시 |
|---|---|---|
| 추세 | 30% | 가격 vs 20/50/200일 이동평균 |
| 모멘텀 | 25% | RSI, MACD 교차 |
| 뉴스 심리 | 20% | Alpha Vantage 심리 점수 (최근 7일) |
| 실적 | 15% | 예상치 대비 EPS 서프라이즈 |
| 거시 국면 | 10% | 금리 방향, 시장(SPY) 추세 |

합산 점수 → **매수 / 보유 / 매도**. 기술적 지표는 일별 시세로 직접 계산해서 API 호출을 아낍니다.

## 6. 무료 키 제약 대응 (하루 25회)

"실시간"은 무료 키로는 불가능하므로 **하루 1회 장 마감 후 일괄 갱신 + 캐시**로 설계합니다.

| 데이터 | 주기 | 호출 수/일 |
|---|---|---|
| 보유 종목 일별 시세 (최대 10개) | 매일 | ≤10 |
| SPY + 보유 섹터 ETF | 매일 | ≤5 |
| 뉴스 심리 (여러 종목 한 번에) | 매일 | 1~2 |
| 국채금리 | 매일 | 1 |
| 기업 개요 / 실적 | 주 1회 순환 | ~2 |
| CPI / 기준금리 / 고용 | 월 1회 순환 | ~1 |
| **합계** | | **~20 (여유 5회는 수동 새로고침용)** |

유료 키로 바꾸면 갱신 주기만 늘리면 되도록 설계합니다.

## 7. 기술 구조

- **프레임워크**: Next.js (App Router) + TypeScript + Tailwind
- **차트**: Recharts (가격/지표), React Flow (인과 흐름도)
- **DB**: Postgres (Neon 무료) + Drizzle ORM. 보유 종목, 일지, API 캐시 저장
- **정기 갱신**: Vercel Cron (하루 1회, 미국 장 마감 후)
- **AI**: Anthropic SDK, 브리핑·해설은 하루 1회 생성 후 캐시 (비용 최소화)
- **비밀값**: `ALPHAVANTAGE_API_KEY`, `ANTHROPIC_API_KEY`, `DATABASE_URL` → 서버 환경변수
- **배포**: Vercel

## 8. 구현 단계 (제안)

1. **뼈대**: Next.js 프로젝트, DB 스키마, 보유 종목 입력
2. **데이터**: Alpha Vantage 수집기 + 캐시 + 크론
3. **포트폴리오**: 손익, 벤치마크 비교, 자산 배분
4. **분석**: 지표 계산, 시그널 점수
5. **AI 해설**: 브리핑, 종목 전망, 인과 흐름도
6. **학습**: 용어 툴팁, 투자 일지

## 9. 확인이 필요한 점

- DB로 Neon Postgres를 써도 되는지 (대안: Supabase, 또는 로그인 없이 쓰는 1인용)
- 로그인 필요 여부 (1인용이면 간단한 비밀번호 보호만)
- 시그널 가중치 초안에 동의하는지
- 투자 정보는 참고용이며 최종 판단은 사용자 책임이라는 안내 문구 표시
